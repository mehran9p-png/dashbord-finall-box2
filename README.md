# 💎 ترمینال فرماندهی ثروت | Wealth Terminal Pro V25 (Institutional Edition)

داشبورد فوق‌حرفه‌ای مدیریت ثروت چنددارایی (بورس تهران، کریپتو، استیبل‌کوین‌های شبکه اتریوم، کلکسیون NFT تلگرام، مهندسی وام ۳۰ میلیونی، استرس‌تست بازار و میز CFO دلار) — بدون نیاز به سرور و آماده اجرا روی **GitHub Pages** و **Google Sites**.

## ✨ امکانات نسخه V25 Institutional Pro
1. **موتور قیمت‌گیری زنده چندمنبعی (Client + GitHub Action)**:
   - دریافت مستقیم و خودکار قیمت‌ها از **TSETMC**، **BrsApi**، **Tetherland**، **Nobitex**، **CoinGecko** و **Coinbase**.
2. **نمای فرماندهی اجرایی (Bento Command Center)**:
   - ثروت کل ناخالص (تومان و دلار)، ثروت خالص پس از کسر بدهی وام، بازده سالانه **XIRR**، نوار ترکیب دارایی‌ها و **ویجت هدف استقلال مالی** با تخمین ماه رسیدن به هدف.
3. **رادار هوشمند بورس تهران (۱۱ نماد) + نقشه حرارتی (Treemap)**:
   - نمایش جدول ۱۱ ستونه حرفه‌ای روی دسکتاپ و کارت‌های بازشونده روی موبایل + ویرایش درجا (Inline) میانگین خرید و یادداشت هر سهم.
4. **شکارچی کف کریپتو (Dip Sniper) و خزانه Dry Powder**:
   - مدیریت موجودی `LUSD` و `USDT` روی شبکه اتریوم + محاسبه ۴ پله خرید لیمیت برای `BTC`، `ETH` و `SOL` بر اساس فاصله از سقف ۹۰ روزه و `SMA200`.
5. **مهندسی وام ۳۰ میلیون تومانی (۲۳٪) و شبیه‌ساز تسویه زودهنگام**:
   - جدول اقساط ۱۲ ماهه، نوار پیشرفت نقطه سر‌به‌سر و ماشین‌حساب تسویه زودهنگام در ماه دلخواه با محاسبه سود بخشیده‌شده بانکی.
6. **آزمایشگاه استرس‌تست بازار (What-If Shock Simulator) و شبیه‌ساز ۵ ساله رشد مرکب**:
   - ۴ اسلایدر زنده برای شبیه‌سازی جهش/سقوط دلار (۱۸۰ تا ۴۵۰ هزار تومان)، بیت‌کوین ($40k تا $160k)، شاخص بورس و طلا/NFT.
7. **میز CFO دلار (SMA90 Buy Zones)، میز ریبالانس عملیاتی (±۲٪) و دفتر کل تراکنش‌ها**:
   - ثبت خرید، فروش، سود تقسیمی مجمع (`DPS`) و کارمزد با خروجی `CSV` و قابلیت `Undo`.

## 🚀 راهنمای گام‌به‌گام ساخت ریپازیتوری و بالا آوردن سایت در GitHub Pages

### روش ۱: آپلود مستقیم از طریق مرورگر (سریع‌ترین روش — ۲ دقیقه)
1. وارد اکانت GitHub خود شوید و از بالا سمت راست روی **`+`** و سپس **`New repository`** کلیک کنید.
2. نام ریپازیتوری را مثلاً `wealth-terminal` بگذارید، گزینه **`Public`** را انتخاب کنید، تیک **`Add a README file`** را بزنید و روی **`Create repository`** کلیک کنید.
3. فایل زیپ کامل پروژه (`wealth-terminal-pro.zip`) را روی کامپیوتر یا گوشی خود از حالت فشرده خارج (Extract) کنید.
4. در صفحه ریپازیتوری گیت‌هاب، روی **`Add file`** ⬅ **`Upload files`** کلیک کنید.
5. تمام فایل‌ها و پوشه‌ها (`index.html`، `sw.js`، `manifest.json`، پوشه `data`، پوشه `scripts` و پوشه `.github`) را بکشید و در صفحه رها کنید (Drag & Drop).
6. در پایین صفحه روی دکمه سبز **`Commit changes`** کلیک کنید.
7. برای فعال‌سازی سایت:
   - وارد تب **`Settings`** (تنظیمات ریپازیتوری) شوید.
   - از منوی سمت چپ روی **`Pages`** کلیک کنید.
   - در بخش **Build and deployment**، زیر قسمت **Branch**، گزینه `None` را به **`main`** تغییر دهید و پوشه را روی **`/ (root)`** بگذارید و **`Save`** را بزنید.
   - پس از ۱ دقیقه صفحه را رفرش کنید؛ لینک زنده سایت شما (`https://<username>.github.io/wealth-terminal/`) بالای صفحه نمایش داده می‌شود!

## 🌐 نحوه قرار دادن در Google Sites (گوگل سایت)
1. وارد [sites.google.com](https://sites.google.com) شوید و یک سایت جدید باز کنید.
2. از منوی سمت راست روی **`Embed` (جاسازی)** کلیک کنید.
3. دو روش دارید:
   - **روش با لینک GitHub Pages**: در تب **By URL**، آدرس GitHub Pages خود را وارد کنید.
   - **روش بدون نیاز به گیت‌هاب (مستقیم)**: تب **`Embed code`** را انتخاب کنید، کل کد فایل `index.html` را داخل آن Paste کنید و **`Insert`** را بزنید!
